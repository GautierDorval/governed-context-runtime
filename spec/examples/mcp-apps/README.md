# GCR MCP Apps companion

This is the isolated source of a local fictional prototype, not a hosted Runtime service. Read the [English guide](../../../docs/en/mcp-apps.md) or [guide français](../../../docs/fr/mcp-apps.md) before connecting a client.

Do not run npm install here. Materialize an execution artifact outside the reference checkout with `prepare.mjs`; install the companion's own lockfile there. The root reference package retains its dependency policy and historical bytes.

The optional short/full nonce diagnostic is described in both guides. It is off by default and never changes the verified pack. See the [dated qualification and initial publication addendum](../../../records/mcp-apps-2026-10-26.md). New browser-only diagnostic modules and their risk tests are explicitly inventoried in `package-policy.json` under the existing code licence; no dependency or licence rule is relaxed.

The selector can prepare a model-visible `read_gcr_pack` request after verified inspection, independently of `updateModelContext`. Message preparation, actual tool invocation and model response remain separate states. The direct French text trial T1 and the separate button-to-answer trial T3 succeeded on 2026-10-27. T3 reused the private conversation after the T2 cancellation, with one effective text-tool call and 11 exact list entries. This is a bounded French fictional result, not a real English trial or a reliability rate. The native context-update route remains experimental. See the guides and dated record.
