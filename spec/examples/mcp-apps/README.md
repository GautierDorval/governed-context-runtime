# GCR MCP Apps companion

This is the isolated source of a local fictional prototype, not a hosted Runtime service. Read the [English guide](../../../docs/en/mcp-apps.md) or [guide français](../../../docs/fr/mcp-apps.md) before connecting a client.

Do not run npm install here. Materialize an execution artifact outside the reference checkout with `prepare.mjs`; install the companion's own lockfile there. The root reference package retains its dependency policy and historical bytes.
