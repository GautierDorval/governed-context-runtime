## Actual Desktop observation

The client used local stdio and the fictional catalog only. Server initialization, tool discovery, `open_gcr_selector`, resource read and `inspect_gcr_pack` were observed in the client log. The UI visibly showed the French pack identity, Quebec-only scope, favourable project-specific written evaluation, excluded cases and forbidden action inferences.

The explicit context button moved from displayed to submitted to acknowledged. The explanation button invoked `ui/message`; this client prepared a draft in its composer, requiring a separate send confirmation. An acknowledgement therefore did not establish that a model response had occurred. After confirmation, the model said the pack was unavailable; a bounded retry after the previous turn ended had the same result. No universal incompatibility or absence of value is inferred from these observations.

The HTML used in this client observation had SHA-256 `2e05c64947d37f011a3e2b5d1a021ae217ce7fa956aa9400e1b31c58616f0e5e`. Its `data.mjs` and `session.mjs` had hashes `31c5282c23c5ceec3c753ecd5ae72837d8678d75b895e8b3b88dab5c39a205f1` and `eb49eeddc96c27ed31f1a7fcf18193952fb13be7f7d16fc968dec5c42cb293ba`. Subsequent presentation changes shorten the mobile selector, show the selected version before inspection, label the host acknowledgement conservatively and explain the composer confirmation. The catalog text now explicitly separates a shared corpus root from language-specific pack identities and excludes its display label from fallback arguments. Independent review also led to complete archived-source inventory assertions, pending-disconnection checks and a visible disabled style for the secondary button. These changes receive local regression checks; the observation above is tied to the stated build.

A generated-script insertion defect was found and corrected before this observation. Resource URIs now include the HTML digest to avoid reuse of an older cached build. A syntax check of the generated inline module guards the insertion. A simulated host alone had not established actual client compatibility.
