# Reporting a security concern

Report privately through GitHub’s private vulnerability reporting (repository **Security** tab, **Report a vulnerability**), or contact Gautier Dorval through the existing public contact address, `info [at] pagup.com`, shown on the [contact page](https://gautierdorval.com/en/contact/). Use a subject identifying Governed Context Runtime and include the affected public revision with a minimal synthetic reproduction. Do not include credentials, private datasets or personal information in a public issue.

This is the existing general contact channel, not a dedicated monitored security service; no response-time guarantee is made. The public reference contains no production signing key. The bundled public key and clock are for a fictional offline exercise only.

Read the [verification boundaries](docs/verification.md) before treating a digest, signature or test result as a security guarantee. This reference provides no hosted service and cannot certify deployment, revocation freshness, source truth or model fidelity.
